# La Fonda de la Abuela

A casual VR management game for Meta Quest 3, made in Unity 6. You play the grandma running her own diner:
customers sit at the bar, and you build their orders by grabbing ingredients and dropping them on a tray.

The full game design and the project rules are in [CLAUDE.md](CLAUDE.md) (in Spanish). Third-party assets and
their licenses are in [CREDITS.md](CREDITS.md).

## Requirements

- **Unity 6000.6.10f1** exactly. Install it from Unity Hub (*Installs → Install Editor → Archive*).
  - Add the **Android Build Support** module (with OpenJDK and Android SDK/NDK) if you will build for the Quest.
- **Git** and **Git LFS**. Models, textures and audio are stored with LFS.

## Get the project

Run this once per computer, **before cloning**:

```bash
git lfs install
```

Then clone the repository:

```bash
git clone https://github.com/AliEli-bit/LaFondaDeLaAbuela.git
```

If you cloned without LFS, models show up as small text files. Fix it from the repository folder with
`git lfs pull`.

Open the folder in Unity Hub (*Add → Add project from disk*). The first import takes several minutes.

## Play it in the editor (no headset)

1. Open `Assets/Scenes/Fonda.unity`.
2. Press **Play**. The **XR Interaction Simulator** drives the headset and controllers with keyboard and mouse.
   It is turned on in *Project Settings → XR Plug-in Management → XR Interaction Toolkit →
   "Use XR Interaction Simulator in scenes"*.
3. OpenXR errors in the Console are expected without a headset.

**Quest Link does not work on macOS.** To test on a real Quest, build an Android APK and install it with
Meta Quest Developer Hub.

## How the scenes are made

The playable scene is **generated by code**. Do not edit `Fonda.unity` by hand: change the builder and rebuild.

| Menu | Builds | Source |
|---|---|---|
| *Tools → Fonda → Build Fonda Scene* | `Assets/Scenes/Fonda.unity` (playable) | `FondaSceneBuilder`, `FondaCoreLoopBuilder` |
| *Tools → Fonda → Build Sketch Scene (Boceto)* | `Assets/Scenes/FondaBoceto.unity` (look only) | `FondaSketchBuilder` |

The builders are in `Assets/Scripts/Editor/`. *Build Fonda Scene* always replaces `Fonda.unity` without asking.
It also runs headless:

```bash
<Unity> -batchmode -quit -projectPath . -executeMethod FondaSceneBuilder.Build
```

If two branches conflict on `Fonda.unity`, do not merge the scene file: take either side, then run *Build Fonda Scene* again and commit the result.

The customer characters are generated in Blender from `Tools/Blender/fonda_figure.py`. See
[Tools/Blender/README.md](Tools/Blender/README.md).

## Project layout

| Folder | Contents |
|---|---|
| `Assets/Scripts/Gameplay/` | Game components (customers, seats, trays, tips, shift clock, sounds) |
| `Assets/Scripts/Data/` | ScriptableObject definitions (ingredients, recipes, difficulty, customer types, sounds) |
| `Assets/Scripts/Editor/` | Scene builders and import rules |
| `Assets/Tests/EditMode/` | Edit Mode tests |
| `Assets/Tests/PlayMode/` | Play Mode tests (load the Fonda scene and drop ingredients with physics) |
| `Assets/Art/` | Project art (characters, sketch materials) |
| `Assets/ThirdParty/` | Third-party packs (KayKit Restaurant Bits, Kenney audio) |
| `Tools/Blender/` | Character generator for Blender |
| `odd/tasks/` | Feature task logs |

## Tests

Open *Window → General → Test Runner*, choose **EditMode** and click **Run All**, then do the same in **PlayMode**.
The Play Mode tests use `Assets/Scenes/Fonda.unity`, so rebuild the scene first if you changed a builder. Run them before opening a
pull request.

## Working together

- Keep `main` working. Do not push to it directly.
- Make one branch per task from an up-to-date `main`, for example `feat/sauce-bottles` or `fix/tray-socket`.
- Write commit messages as [Conventional Commits](https://www.conventionalcommits.org/): `feat: ...`,
  `fix: ...`, `docs: ...`, `chore: ...`.
- Open a pull request to `main` and ask a teammate to review it.
- Agree in the team chat before two people change the same builder or prefab at the same time.
- Always commit the `.meta` file together with its asset.
